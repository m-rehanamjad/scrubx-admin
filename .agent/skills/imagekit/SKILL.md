# ImageKit Integration Skill for Next.js App Router

This skill establishes standards for media management in ScrubX using **ImageKit** for secure upload, CDN delivery, responsive transformations, and automatic file cleanup.

---

## 1. Storage Organization & Security Rules

1. **Folder Conventions**:
   - `/products/`: Public catalog product photos and color variant images.
   - `/categories/`: Category thumbnail and banner graphics.
   - `/proofs/`: Customer payment screenshot uploads (JazzCash, EasyPaisa, Bank deposit receipts).
   - `/engraving/`: Customer uploaded logos and vector files (Private, custom-embroidered).
2. **File ID Tracking**:
   - Every uploaded image MUST store both its `url` and `imagekit_file_id` (e.g. In `product_images` or `order_item_engraving`).
   - When an image or product is deleted, the corresponding file in ImageKit MUST be purged via the ImageKit SDK using `imagekit.deleteFile(fileId)`.
3. **Restricted Access for Sensitive Media**:
   - Customer logos and payment receipts must not be publicly guessable. Use secure signed URLs or private folders where required.

## 2. Server Configuration (`src/lib/imagekit.ts`)

Initialize the server-side ImageKit SDK instance:

```typescript
// src/lib/imagekit.ts
import ImageKit from "imagekit";

if (!process.env.IMAGEKIT_PRIVATE_KEY) {
  throw new Error("Missing IMAGEKIT_PRIVATE_KEY environment variable");
}

export const imagekit = new ImageKit({
  publicKey: process.env.NEXT_PUBLIC_IMAGEKIT_PUBLIC_KEY!,
  privateKey: process.env.IMAGEKIT_PRIVATE_KEY!,
  urlEndpoint: process.env.NEXT_PUBLIC_IMAGEKIT_URL_ENDPOINT!,
});
```

## 3. Upload Patterns in Next.js App Router

### Pattern A: Direct Client-Side Upload (Recommended for Large Files)

To avoid sending heavy multipart payloads through Next.js serverless functions, upload directly to ImageKit using client-side tokens generated by a Server Route Handler:

#### 1. Authentication Parameter Route (`src/app/api/upload/auth/route.ts`):
```typescript
// src/app/api/upload/auth/route.ts
import { NextResponse } from "next/server";
import { imagekit } from "@/lib/imagekit";
import { requireAdmin } from "@/lib/auth-guard";

export async function GET() {
  // Ensure user is authorized to upload
  await requireAdmin();

  const authParams = imagekit.getAuthenticationParameters();
  return NextResponse.json(authParams);
}
```

#### 2. Client-Side Upload Utility (`src/lib/imagekit-upload.ts`):
```typescript
// src/lib/imagekit-upload.ts
export interface UploadResult {
  fileId: string;
  url: string;
  thumbnailUrl: string;
  name: string;
}

export async function uploadToImageKit(
  file: File,
  folder: "/products" | "/categories" | "/proofs" | "/engraving" = "/products"
): Promise<UploadResult> {
  // 1. Get auth parameters from backend
  const authRes = await fetch("/api/upload/auth");
  if (!authRes.ok) throw new Error("Failed to retrieve ImageKit authentication parameters");
  const authParams = await authRes.json();

  // 2. Prepare upload payload
  const formData = new FormData();
  formData.append("file", file);
  formData.append("fileName", `${Date.now()}-${file.name.replace(/\s+/g, "-")}`);
  formData.append("publicKey", process.env.NEXT_PUBLIC_IMAGEKIT_PUBLIC_KEY!);
  formData.append("signature", authParams.signature);
  formData.append("expire", authParams.expire.toString());
  formData.append("token", authParams.token);
  formData.append("folder", folder);

  // 3. Upload directly to ImageKit API
  const res = await fetch("https://upload.imagekit.io/api/v1/files/upload", {
    method: "POST",
    body: formData,
  });

  if (!res.ok) {
    const errorData = await res.json();
    throw new Error(errorData.message || "ImageKit upload failed");
  }

  const data = await res.json();
  return {
    fileId: data.fileId,
    url: data.url,
    thumbnailUrl: data.thumbnailUrl,
    name: data.name,
  };
}
```

### Pattern B: Server Action Upload (Admin Quick Uploads)

For small files or admin workflows where server-side validation is preferred:

```typescript
// src/actions/upload.ts
"use server";

import { requireAdmin } from "@/lib/auth-guard";
import { imagekit } from "@/lib/imagekit";

export async function uploadServerImage(formData: FormData, folder: string = "/products") {
  await requireAdmin();

  const file = formData.get("file") as File;
  if (!file) throw new Error("No file uploaded");

  const arrayBuffer = await file.arrayBuffer();
  const buffer = Buffer.from(arrayBuffer);

  const res = await imagekit.upload({
    file: buffer,
    fileName: `${Date.now()}-${file.name.replace(/\s+/g, "-")}`,
    folder,
  });

  return {
    fileId: res.fileId,
    url: res.url,
    thumbnailUrl: res.thumbnailUrl,
  };
}
```

## 4. Deleting Images from ImageKit

When a product or photo record is removed from PostgreSQL, clean up the asset in ImageKit:

```typescript
// src/actions/media.ts
"use server";

import { requireAdmin } from "@/lib/auth-guard";
import { imagekit } from "@/lib/imagekit";

export async function deleteImageKitFile(fileId: string) {
  await requireAdmin();
  try {
    await imagekit.deleteFile(fileId);
    return { success: true };
  } catch (err) {
    console.error(`Failed to delete ImageKit file ${fileId}:`, err);
    return { success: false, error: "ImageKit deletion failed" };
  }
}
```

## 5. ImageKit Dynamic Transformations & Next.js `<Image />`

Use ImageKit's URL transformation features to optimize images for WebP/AVIF format, dimension resizing, and quality:

### Helper: `src/lib/imagekit-url.ts`
```typescript
// src/lib/imagekit-url.ts
export function getImageKitUrl(
  pathOrUrl: string,
  transformations: { width?: number; height?: number; quality?: number; format?: "auto" | "webp" | "avif" } = {}
): string {
  const endpoint = process.env.NEXT_PUBLIC_IMAGEKIT_URL_ENDPOINT!;
  if (!pathOrUrl) return "";

  // If already absolute URL not pointing to imagekit endpoint, return as is
  if (pathOrUrl.startsWith("http") && !pathOrUrl.includes(endpoint)) {
    return pathOrUrl;
  }

  const cleanPath = pathOrUrl.replace(endpoint, "").replace(/^\//, "");
  const parts: string[] = [];

  if (transformations.width) parts.push(`w-${transformations.width}`);
  if (transformations.height) parts.push(`h-${transformations.height}`);
  if (transformations.quality) parts.push(`q-${transformations.quality}`);
  parts.push(`f-${transformations.format || "auto"}`);

  const trString = `tr:${parts.join(",")}`;
  return `${endpoint}/${trString}/${cleanPath}`;
}
```

### Integration in Next.js Components:
```tsx
import Image from "next/image";
import { getImageKitUrl } from "@/lib/imagekit-url";

export function ProductThumbnail({ src, alt }: { src: string; alt: string }) {
  return (
    <Image
      src={getImageKitUrl(src, { width: 160, height: 160, quality: 80 })}
      alt={alt}
      width={80}
      height={80}
      className="rounded-md object-cover"
      unoptimized // ImageKit handles transformation & compression at the edge
    />
  );
}
```
